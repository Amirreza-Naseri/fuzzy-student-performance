# Research reference

This project is an independent Python implementation/reproduction study based on:

Tengku Zatul Hidayah Tengku Petra and Mohd Juzaiddin Ab Aziz (2021),
**"Analysing Student Performance In Higher Education Using Fuzzy Logic Evaluation"**,
*International Journal of Scientific & Technology Research*, Vol. 10, Issue 01, pp. 322-327.

Original article:
https://ijstr.org/final-print/jan2021/Analysing-Student-Performance-In-Higher-Education-Using-Fuzzy-Logic-Evaluation.pdf

The paper's Table 2 and Table 3 define the input membership functions, Tables 4-6
specify the rule bases, and Tables 7-8 provide the sample values used for validation.

This repository is not affiliated with the paper's authors or publisher. The Python
code is an independent implementation. Output membership-function breakpoints that
are not tabulated numerically in the article are explicitly treated as reconstructed
assumptions rather than exact paper parameters.
