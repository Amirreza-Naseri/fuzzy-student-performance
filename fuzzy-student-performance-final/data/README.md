# Data

The two CSV files transcribe the 20-student sample values reported in Tables 7 and 8
of Tengku Petra & Ab Aziz (2021). They are included only to reproduce and audit the
small published experiment.

- `table7_students.csv`: Semester GPA, knowledge, problem-solving, and published
  Academic/Cognitive values.
- `table8_students.csv`: Published Academic Performance, Personality Development,
  conventional overall score, and fuzzy overall score.

See `../CITATION.md` for the publication reference.
