## Create and push

Create an empty public repository named `fuzzy-student-performance`, then from this folder run:

```powershell
git init
git add .
git commit -m "Initial commit: Mamdani fuzzy student performance system"
git branch -M main
git remote add origin https://github.com/Amirreza-Naseri/fuzzy-student-performance.git
git push -u origin main
```

If `origin` already exists:

```powershell
git remote set-url origin https://github.com/Amirreza-Naseri/fuzzy-student-performance.git
git push -u origin main
```
